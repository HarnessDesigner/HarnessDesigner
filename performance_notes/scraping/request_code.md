# harness_designer/scraping/request_code.py

RequestSpec → requests-library code (generate_request_code, generate_page_load). Cookie and Authorization headers are never written into generated code — a deliberate security choice, not an oversight. Handles JSON, urlencoded, and multipart request bodies.

Cold path (220 lines): the AST pass finds no per-frame or per-event handlers, no nested loops, no loops that allocate Qt or NumPy objects, no timers and no threads. It runs when its feature is opened or used, so there is nothing here worth optimising.

Status: static read of the code only. Nothing here has been profiled.
