# harness_designer/scraping/soft_wrap.py

SoftWrap — the document with extra line breaks inserted for display (minified pages are often one giant line) plus the map from display positions back to offsets in the original text, including across CRLF line endings.

Cold path (167 lines): the AST pass finds no per-frame or per-event handlers, no nested loops, no loops that allocate Qt or NumPy objects, no timers and no threads. It runs when its feature is opened or used, so there is nothing here worth optimising.

Status: static read of the code only. Nothing here has been profiled.
