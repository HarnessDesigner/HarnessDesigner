# harness_designer/ui/concentric_section/wire_painter.py

QPainter drawing of one cable, in millimetres (the caller has translated to the cable's centre and scaled). paint_conductor = the insulation disc (the OD, primary colour), the stripe's cross-section (a piece of the insulation ring, STRIPE_ARC_DEG wide and STRIPE_DEPTH_FRACTION of the wall deep) and the metal conductor disc. paint_cable = jacket disc, shield ring (with a dotted line so it reads as a braid), the core fill, then every conductor at its place in the pack; a coax is the same drawing (one conductor whose "insulation" is the dielectric, plus shield and jacket).

Cold path (130 lines): the AST pass finds no per-frame or per-event handlers, no nested loops, no loops that allocate Qt or NumPy objects, no timers and no threads. It runs when its feature is opened or used, so there is nothing here worth optimising.

Status: static read of the code only. Nothing here has been profiled.
