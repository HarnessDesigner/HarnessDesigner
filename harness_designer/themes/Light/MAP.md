## FILES

#### Light.qss

The light theme's Qt stylesheet. `themes.load_theme("Light")` rewrites its baked-in `:/qss_icons/dark/rc` resource prefix to point at this theme's own `icons/` folder before applying it.

## FOLDERS

#### icons/

The light theme's UI chrome glyphs: window controls, tree-view branch and arrow icons, checkbox/radio/toolbar-grip states. Each is usually in `@1x`/`@2x` and normal/disabled/focus/pressed variants (208 PNGs). Same file set as the other theme's `icons/`.
